| Бизнес-возможность L2 | Целевая модель | Обоснование |
|---|---|---|
| Кассовые операции (POS) | SaaS (Buy) | Стандартная функциональность ритейла. Единая облачная POS-платформа с offline-режимом заменяет локальные кассовые системы. |
| Программа лояльности | SaaS (Buy) | Готовая CRM/Loyalty с бонусами, клиентскими профилями и историей покупок. Интеграция с Promo Engine. |
| Расчёт премий | SaaS (Buy) | Стандартные HRM/Payroll-процессы. Централизация правил премирования и отказ от локальных расчётных систем. |
| Приёмка товара | SaaS (Buy) | Стандартизированные процессы приёмки со сканерами и передачей документов в ERP. |
| Локальные закупки | In-house ERP + SaaS | Централизация учёта договоров и заказов в существующей ERP. SaaS-портал поставщиков при необходимости. |
| Печать ценников | SaaS (Buy) + On-prem Edge | Централизованное управление ценами и шаблонами. Физическая печать остаётся в магазине. |
| Инкассация | On-prem / Outsource | Физические операции выполняются локально или подрядчиком, финансовые данные передаются в ERP. |
| Фискализация | SaaS + On-prem | Централизованное управление с сохранением обязательных локальных фискальных компонентов. |
| Учёт остатков | In-house ERP + PaaS | ERP остаётся системой учёта. Облачные сервисы обеспечивают оперативную синхронизацию остатков. |
| Каталог и мастер-данные | In-house ERP / SaaS PIM | ERP остаётся источником мастер-данных. SaaS PIM используется при необходимости. |
| Promo Engine | PaaS (Build / Migrate) | Собственный движок промоакций является стратегическим активом. Сохраняем бизнес-логику и переносим инфраструктуру в облако. |
| Smart Fulfillment | PaaS (Build / Migrate) | Ключевое конкурентное преимущество. Интеллектуальная маршрутизация и распределение заказов остаются собственной разработкой. |
| ATP и резервирование | PaaS (Build) | Уникальная логика доступности и резервирования товаров требует глубокой интеграции со Smart Fulfillment. |
| Click & Collect | PaaS (Build) + SaaS POS | Логика заказа и резервирования остаётся собственной. Выдача заказов интегрируется с POS. |
| ERP / Финансовый учёт | In-house (Retain) | Существующая мощная ERP сохраняется. Замена на SaaS нецелесообразна без дополнительного обоснования. |
| Онлайн-витрина | SaaS (Buy) | Стандартные функции каталога, корзины и оформления заказа реализуются готовым продуктом. Логистика остаётся собственной. |
| HR, графики смен и обучение | SaaS (Buy) | Типовые корпоративные процессы, не формирующие конкурентного преимущества. |
| IAM / SSO | SaaS (Buy) | Централизованная аутентификация, авторизация и управление доступами на базе готового решения. |
| Интеграционная платформа | PaaS (Build / Configure) | API Gateway, Event Bus, управляемые очереди и адаптеры обеспечивают интеграцию всех систем. |
| Локальные legacy-серверы | Decommission | Вывод из эксплуатации после миграции функций и проверки корректности работы новых систем. |
